# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal
appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

Be respectful, accept constructive criticism, and keep the discussion on the
work. Harassment, insulting comments, trolling, and publishing someone else's
private information are not acceptable.

## Enforcement

Report unacceptable behavior to the maintainers through a private
[GitHub security advisory](https://github.com/kidandcat/cairn/security/advisories/new)
on this repository. Do not file a public issue for a conduct report.

Maintainers will review the report and may remove comments or reject
contributions that break this code. This code applies in project spaces and
when someone is representing the project in public.
